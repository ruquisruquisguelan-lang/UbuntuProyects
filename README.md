# Proyecto Guelaguetza · EMMA — co-diseño (para Lili)

Sitio de co-diseño para **tía Lili**. Punto de entrada: **`index.html`**.
Al abrirlo, Lili ve *lo que tiene que hacer*: su camino, cómo vestir EMMA, y la app para vestirla.

## Archivos
- `index.html` — portada para Lili (empieza aquí).
- `CAMINO_Lili_estilo_Apple.html` — su camino, paso a paso.
- `VESTIR_EMMA_guia_Lili.html` — las reglas de la piel de EMMA.
- `portada.html` → `EMMA_bienvenida.html` → `EMMA_alumno/docente/profesional.html` → `taller_autonomia_v8_Ana.html` — la app.
- `FLUJO_EMMA_estilo_Apple.html` — el ciclo EMMA.

Todo HTML estático, offline, sin dependencias.

## Publicar en GitHub Pages
1. Crea un repo nuevo y sube todos estos archivos a la raíz.
2. Settings → Pages → Deploy from a branch → `main` / `/ (root)` → Save.
3. En 1–2 min: `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/` — ese link se lo mandas a Lili.

> Las imágenes ordenadas (láminas, iconos, grecas) van en un paquete aparte por su tamaño.
